华为手机的无障碍服务自动关闭

适用于 HarmonyOS 4.x 及以下的相关机型。不同系统版本的菜单名称可能略有差异，可在设置中搜索对应名称。

为什么会发生？

开启 Open Doubao 的无障碍服务后，过一段时间又提示未开启，可能与手机管家的后台清理有关。华为官方说明：清理后台或重启后，第三方应用可能被清理，导致无障碍服务无法启动，开关被系统识别为关闭。详见华为无障碍服务说明。

遇到这种情况，可以先调整后台管理设置，再重新开启服务。

按顺序检查这四项

  1. 将应用启动改为手动管理

    在设置中搜索「应用启动管理」，找到 Open Doubao，关闭「自动管理」，打开「允许自启动」「允许关联启动」「允许后台活动」。

  2. 在最近任务中锁定应用

    打开 Open Doubao 后进入最近任务界面，下拉应用卡片加锁。确认卡片出现锁定标记，避免使用一键清理时将它结束。

  3. 关闭对 Open Doubao 的电池优化

    在设置中搜索「电池优化」，切换到「所有应用」，找到 Open Doubao，选择「不允许」。这里的「不允许」指不允许系统对该应用进行电池优化。详见华为后台运行设置说明。

  4. 重新开启无障碍服务

    进入「设置 → 辅助功能 → 无障碍」，在「已安装的服务」或「下载的服务」中找到 Open Doubao，重新开启。返回应用，确认无障碍状态已恢复。

设置后怎么确认？

先执行一个简单任务，确认助手可以正常操作。随后按平时的方式使用和锁屏，观察无障碍开关是否仍然开启。如果在清理后台或重启后再次失效，检查上述设置并重新开启服务。

这些设置可以减少后台清理带来的影响。系统版本、其他省电策略和重启仍可能影响服务，需要结合实际使用观察。

仍然会关闭？

请在 GitHub Issues 反馈，并附上这些信息：

  • 手机型号、HarmonyOS 版本和 Open Doubao 版本。
  • 问题发生的大致时间，以及当时是否锁屏、清理后台或重启。
  • 上述四项的设置情况，以及无障碍开关是已关闭，还是仍开启但助手无法操作。

如需附上截图或日志，请先遮盖 API Key、账号和聊天内容等私人信息。
