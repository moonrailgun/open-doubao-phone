# Changelog

## [Unreleased]

- Android: Add companion mode with brief comments about what's happening while you play games or watch videos. You can adjust how often it comments.
- Android: Use a favorite picture as your floating bubble avatar, or restore the default at any time.

## [1.1.0] - 2026-10-31

- Android: Let the assistant work on a separate virtual screen on Android 14 and later, without replacing your phone's operating system. Additional setup is required.
- Android and desktop: Check for updates, see what's new and open the download page from the app.
- Desktop: Add installers for Mac, Windows and Linux.
- Android: The assistant remembers what you've discussed during a task, so you can continue from the floating bubble without repeating yourself.
- Android: Keep your progress when a task pauses for your input, with an option to continue if the screen keeps changing.
- Android: Reduce unintended submissions when an input field changes.
- Android: Open or close the floating bubble from the main screen; the assistant remembers your choice when it restarts.
- Android: Write longer messages in the floating panel, with tidier input buttons and task progress displays.
- Desktop: Retry a failed task from the current page or your task history.
- Android and desktop: Make common AI settings easier to find. On desktop, bring model and voice settings together and fix an issue saving some model settings.

## [1.0.1] - 2026-10-20

- Maintenance update: Fix an issue preparing the installation package, with no changes to existing features.

## [1.0.0] - 2026-10-20

- Android: First release for Android 11 and later. Type or say what you want to do, and let the assistant work across your apps.
- Android: Choose and configure the AI services you want to use.
- Android: Follow progress from the floating bubble, pause, resume or stop tasks, and choose which apps the assistant cannot access.
- Android: Keep settings, memories and task history encrypted on your phone, and review past activity.
- Android: Listen to spoken responses using on-device or online voice services.
- Desktop: Connect your computer and phone to the same network, then pair them using a QR code or device code to send tasks, follow progress and view history.
