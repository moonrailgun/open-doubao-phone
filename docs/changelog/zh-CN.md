# 更新日志

## [Unreleased]

- 手机端：从最近任务中划掉应用并退出悬浮球后，无论先关闭哪一个，都会停止任务、陪伴模式、语音监听和播报，以及电脑端的远程接收，直到重新打开应用；保留设置和任务记录。仅返回桌面不会退出应用。
- 官网：首页新增手机端 APK 直接下载入口。
- 手机端与电脑端：新增累计模型用量与成本估算，分别查看任务执行、陪伴模式以及各接口地址下不同模型的费用。可填写每百万 Token 的人民币输入、输出和缓存输入单价，修改后重新估算累计用量；缺少用量或单价的调用单独标注。统计读写异常不再中断任务执行或陪伴模式，用量未能保存时提示累计费用可能偏低。统计从升级后开始，不含语音识别、语音合成和连接测试。
- 手机端：陪伴模式的评论出现、收起和展开输入时，悬浮球保持原位，仅展开对话气泡，不再重复显示头像；顶部胶囊保持小尺寸，减少跳动和干扰。展开对话时，也可将悬浮球拖到屏幕任一侧；输入长文本时，停止按钮仍完整显示在键盘上方。
- 手机端：选择悬浮球头像后，可在圆形预览中拖动、缩放并确认裁切；取消时保留当前头像。旋转屏幕后保留裁切进度，横屏大字体下也可正常操作。
- 手机端：陪伴模式每秒采集画面，结合最近 5 张压缩截图、近期对话、你提供的背景与偏好以及持续更新的摘要理解上下文。默认观察间隔改为 10 秒，设为 1–4 秒时相应减少截图张数，已保存的间隔保持不变；变化不大时可保持安静，回复较慢时仍继续采集画面，也不会积压自动请求。输入或语音期间会暂停采集，但会保留近期对话，也不会因此重复评论同一画面；暂停时发送的问题，会在恢复采集到第一张截图后继续处理；截图耗时超过 1 秒时，较短的观察间隔仍能正常工作。切换应用或窗口后，会丢弃基于旧画面生成的待回复内容。
- 手机端：悬浮球菜单右上角改为直接打开主界面，打开时会暂停前台任务，已在后台运行的任务继续执行；即使暂停时尚未打开目标应用，也能点击继续恢复任务；点击菜单外的空白处仍可收起菜单。

## [1.3.0] - 2026-11-04

- 手机端：增加悬浮球弹窗中停止按钮上方的间距，避免与输入框紧贴。
- 手机端：首页分为「执行」和「陪伴模式」两个标签，任务输入和提示集中在「执行」中；悬浮球开关和头像设置移至设置页新增的「概览」标签。
- 手机端：Debug 版现在可与正式版同时安装，使用独立名称和带橙色 DBG 标记的图标；使用同一签名覆盖安装 Debug 版时保留其设置和记录。
- 手机端：开启陪伴模式后自动收进屏幕顶部胶囊，移除头像绿色边框；评论支持多行展示，较长内容可滚动查看。修复 Android 11–13 上状态栏导致无法观察画面的问题，观察失败时显示重试状态。观察画面和自动点击、滑动时，胶囊与面板持续显示，不再闪烁；Android 11–13 的截图会遮黑浮层覆盖的区域，落在浮层上的自动点击、滑动会被拦截。
- 手机端：可以在陪伴面板中输入聊天或补充上下文，发送后额外触发回复，画面未变化时也会回应。定时观察继续进行，后续回复会参考近期输入，停止陪伴后清空。等待重试时，新输入会立即尝试回复，无需等到下一次定时观察。

## [1.2.0] - 2026-11-03

- 手机端：小浮窗正文独占整行，充分利用两侧空间；打开应用和新对话收进更多菜单。
- 手机端：修复部分华为手机开启手势导航后，以及助手浮窗尚未完全收起时，任务误报画面被遮挡并反复暂停的问题。
- 手机端：新增陪伴模式，玩游戏或看视频时，助手会根据画面给出简短评论，可调整评论频率。陪伴模式从主界面开启，可在悬浮球的展开菜单中停止。
- 手机端：可以用喜欢的图片替换悬浮球头像，也能随时恢复默认头像。
- 手机端：陪伴评论会自动收起，悬浮球拖到屏幕顶部后会缩小停靠，减少对游戏和视频的遮挡；展开评论或面板后拖动时保持当前位置，不再跳动。
- 手机端：陪伴模式可单独开启语音播报，默认关闭；不播报、播报失败或被中断时，评论文字至少显示 5 秒，留出阅读时间。

## [1.1.0] - 2026-10-31

- 手机端：Android 14 及以上支持让助手在独立的虚拟屏幕中执行任务，无需刷机，使用前需额外设置。
- 手机端和电脑端：可以在应用内检查更新、查看更新内容，并打开下载页面。
- 电脑端：新增 Mac、Windows 和 Linux 安装包。
- 手机端：助手会记住当前任务中聊过的内容，可以从悬浮球接着说，不用重复交代。
- 手机端：任务暂停等待你输入时会保留进度；页面一直变化时，也可以选择忽略并继续。
- 手机端：减少输入框发生变化后，助手仍继续提交的情况。
- 手机端：可以在主界面打开或关闭悬浮球，助手重新启动后会记住这个选择。
- 手机端：悬浮输入框支持多行文字，输入按钮和任务进度的显示更整齐。
- 电脑端：任务失败后，可以在当前页面或历史记录中重新尝试。
- 手机端和电脑端：常用模型设置更容易找到；电脑端将模型和语音设置放在一起，并修复部分模型配置无法保存的问题。

## [1.0.1] - 2026-10-20

- 维护更新：修复安装包制作过程中的问题，现有功能不变。

## [1.0.0] - 2026-10-20

- 手机端：首次发布，支持 Android 11 及以上。说出或输入想做的事，助手就能在不同应用之间帮你操作。
- 手机端：可以选择并配置自己使用的 AI 服务。
- 手机端：通过悬浮球查看进度，随时暂停、继续或停止任务，也能指定哪些应用不允许助手访问。
- 手机端：设置、记忆和任务历史在手机上加密保存，可以回看执行记录。
- 手机端：支持语音播报，可选择手机本地或在线语音服务。
- 电脑端：电脑与手机连接同一网络后，可通过扫码或设备码配对，在电脑上发任务、看进度和查历史。
